Purpose: the report's primary causal story - one unknown objective is driven
through dense intelligence and an evidence gate into runtime evolution and an
expanded frontier, then loops back.

=== BEGIN SHARED STYLE BLOCK: Blue-Gold Precision Atlas ===
Art direction: Blue-Gold Precision Atlas. Render one museum-grade editorial
technical-atlas plate at the quality bar of a first-party frontier research-lab
report: fine precise linework, generous negative space, calm balanced
composition, restrained blue-and-gold accents, tactile matte print texture, and
plate-like framing. It must read as a printed scientific atlas plate, never a
marketing graphic, SaaS dashboard, stock 3D render, whiteboard sketch, or Figma
wireframe.

Palette (use only these five colours; any sixth colour or off-palette hue is a
reject):
- bone white #FBFAF6 - paper field / background
- system blue #315BCE - primary runtime structure, modules, and connectors
- deep blue #214884 - secondary structure, framing, and deeper accents
- frontier / evidence gold #C38A20 - reserved SOLELY for the evidence, decision,
  or verified-progress accent; never the default structure colour
- graphite #24272B - labels, hairlines, and subordinate machinery

Composition and linework:
- Hairline strokes about 1 to 1.5 px, precise geometry, measured spacing,
  delicate connectors and arrows whose arrowheads land exactly on their named
  destination.
- Generous negative space and confident restraint; legible in GitHub light and
  dark contexts and when printed to PDF.

Typography (OCR-critical):
- Set EVERY label horizontally, left-to-right, on a level baseline, in a clean
  humanist sans-serif.
- NO vertical text, NO stacked text, NO rotated text, NO curved or
  path-following text, NO character-by-character vertical stacking.
- Keep high figure-to-ground contrast so each label is OCR-legible.
- SPELL EXACTLY every pinned label as quoted; do not invent, translate,
  abbreviate, renumber, reorder, or duplicate any label, and add no label that
  is not pinned.

Canvas:
- 1536 x 1024 pixels, landscape 3:2 (1536x1024). One flat raster plate, no
  border bleed, and no multi-panel montage unless the figure body explicitly
  asks for panels.

Shared negative prompt (reject the raster if any of these appear):
- no cyberpunk, neon, glow, holograms, glassmorphism, or decorative gradients
- no robots, brains, eyes, faces, photoreal people, or anthropomorphic mascots
- no fake 3D dashboards, stock 3D icons, emoji, glossy web badges, gauges, or
  vendor / brand logos
- no watermarks, marketing badges, trophies, medals, ribbons, or success stamps
- no Figma / SaaS / dashboard look, no rounded pastel card grid, no whiteboard
  or Excalidraw sketch
- no code snippets, raw file paths, tiny unreadable text, vertical or curved
  text, or dense paragraphs
- no colour outside the five pinned palette colours

Required relationships / layout (honour every one):
- Draw ONE left-to-right causal path across five stages in this order:
  "Unknown objective" -> "Dense Intelligence Runtime" -> "Evidence Gate" ->
  "Runtime Evolution" -> "Expanded OOD Frontier".
- Place the four roles "Manager", "Planner", "Engineer", "Reviewer" INSIDE the
  "Dense Intelligence Runtime" stage.
- Place the six capability-state components "Memory", "Skills", "Tools",
  "Verifiers", "Routing", "Evaluations" INSIDE the "Runtime Evolution" stage.
- Draw ONE return path from "Expanded OOD Frontier" back to the next
  "Unknown objective".
- "Evidence Gate" is the ONLY gold element (the single decision point); every
  other stage and all runtime structure is system/deep blue, labels graphite.
- Set the banner headline "Every run expands the frontier." across the top, and
  keep the two graphite caveats "model parameters remain fixed" and
  "capability is not guaranteed to grow every run" clearly visible.

Figure-specific negative prompt (reject the raster if any appears):
- no performance numbers, plotted curves, axes, or benchmark scores; this is a
  causal schematic, not a measured plot
- do not gold-highlight anything except the single Evidence Gate
- do not imply guaranteed capability growth; keep both caveats legible

Semantic contract (the finished plate must read as):
One unknown, out-of-distribution objective enters a dense-intelligence runtime
where four roles carry the reasoning, passes a single evidence gate, evolves the
runtime's capability state (memory, skills, tools, verifiers, routing,
evaluations), and expands the frontier - which then poses the next unknown
objective. The model parameters remain fixed and capability is not guaranteed to
grow on every run; the gold evidence gate, not optimism, is what advances the
frontier.
