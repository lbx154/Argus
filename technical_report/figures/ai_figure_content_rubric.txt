Argus AI figure - EXACT-CONTENT review rubric
Rubric id: ai-figure-content-rubric-v1  (produces <stem>.content-review.json)
Spec: docs/superpowers/specs/2026-07-15-ai-redraw-structural-report-figures-design.md

Role: You are the SECOND, independent reviewer, and you run on ALL SIX
structural/concept figures. You do exact-content verification: every pinned
label is present and spelled EXACTLY, the label set is complete, and NO extra or
invented label or number appears. Read the raster directly; do not rely on the
prompt text. The two data figures (public_results, paper_portfolio) remain
deterministically drawn and are NOT reviewed here.

Output a JSON object <stem>.content-review.json with at least these fields:
- "keep_or_regenerate": "keep" or "regenerate".
- "confirmed_labels": every pinned label you can read exactly in the raster.
- "extra_tokens_present": every number or label you can read that is NOT a
  pinned token (must be empty to keep).
- "unresolved_numeric_mismatches": every pinned number (for example
  "112 typed events" or "1,800 s decision budget") that the raster renders
  incorrectly, misspelled, or rounded. Must be empty to keep.

Keep only when: the confirmed labels cover the full pinned set for that figure,
extra_tokens_present is empty, and unresolved_numeric_mismatches is empty. Any
missing pinned label, any misspelling, or any extra token forces "regenerate".

Applies to all six structural figures: Master Spine, Dense Intelligence,
Three Planes, Argus Architecture, Mission Lifecycle, and
Long-Horizon Reliability. For every one of them, verify the exact pinned label
set from that figure's prompt file with no additions and no rounded or
reformatted numbers.
