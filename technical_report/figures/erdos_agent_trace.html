How four Argus roles turn an open-ended goal into reviewed progress

The math is one output. The trace shows the Agent workflow that plans, executes, rejects, repairs, accepts, and retains it.

Manager

Own the campaign

Commits the objective and lifetime; repairs operational state; alone advances or rolls back stages.

Authority: objective · route · stage

Planner

Choose bounded work

Reads accepted state and open blockers; emits missions, dependencies, and explicit success criteria.

Authority: next tasks · DAG · checklist

Engineer

Produce results

Searches sources, runs tools and experiments, and writes artifacts, proofs, logs, and checkpoints.

Authority: execution · artifacts

Reviewer

Decide acceptance

Inspects artifacts and logs; issues done / continue / blocked; canonicalizes retained state.

Authority: completion · admitted state
