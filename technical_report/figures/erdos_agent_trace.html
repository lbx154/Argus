Representative vertical run · observed campaign

Four recurrent roles turn one open objective into reviewed progress

The workflow tests routes, repairs proof packages, retains failed branches, and continues from accepted state.

M

Manager

Preserves the objective and owns Stage advance or rollback.

Authority: objective · route · Stage
P

Planner

Turns reviewed state into bounded missions and success criteria.

Authority: next task · dependencies
E

Engineer

Retrieves sources, runs checks, and writes proofs and artifacts.

Authority: execution · artifacts
R

Reviewer

Accepts, revises, or blocks work before it enters durable state.

Authority: completion · admitted state

P

E/R

2 · Test the route
P
Choose a cheap falsifier before expensive proof search.
E
Run a witness check. A known graph kills the proposed reduction.
R/M
Reject the route, retain the branch, and continue the campaign.
3 · Build the proof
P
Set a theorem contract. Computation alone cannot close the mission.
E
Write the package: proof, checks, lemma graph, and limits.
R/E
Request repair, revise, and resubmit against the same criteria.
4 · Strengthen state
P
Require strict progress from the current theorem frontier.
E
Advance artifacts: improve a bound and prove bridge results.
R
Certify correctness and relation to prior work.
5 · Retain & continue
R
Write the checkpoint: accepted claims, dead routes, and blockers.
M
Advance or roll back from reviewed results rather than activity.
P/E
Launch the next mission from retained state, not from scratch.
