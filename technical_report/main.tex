\begin{abstractbox}
\small
\textbf{Abstract.}
Long-horizon reasoning is not repeated one-shot completion. Intermediate proofs,
measured bottlenecks, failed routes, and specification contradictions can be
valuable before a terminal artifact exists. Only when verified against explicit
criteria can such signals justify refining the initial goal, constraint, or verifier.

We present \systemname, a verification-centered runtime for persistent,
pivot-capable long-horizon reasoning. Manager, Planner, Engineer, and Reviewer execute bounded missions over
a durable task contract. Long-horizon reasoning is not merely persistence:
verification determines when to continue, stop, replan, or surface evidence and
alternatives for user clarification or authorization. Any resulting pivot is
recorded in the durable contract, separating evidence-backed refinement from goal
drift. Meanwhile, staged records of attempted approaches, accepted and
rejected results, skills, verifiers, and routing update the runtime while model
weights remain fixed. This \emph{verifier-gated runtime self-evolution} improves how later missions
navigate between the current goal and constraints. Between user decision boundaries,
the harness remains fully autonomous.

In fully autonomous runs with no human intervention during execution, the same
harness remains effective across seven GPT-5.5 benchmark arenas. It reaches
approximately \SWEProArgusAccuracy\% (behind only Mythos \& Fable 5) on
SWE-Bench Pro versus \SWEProDirectAccuracy\% for Direct Copilot. After
verifier-gated runtime evolution, mature SWE-Bench waves use \SWEProTokenReduction\% fewer solve
input Tokens per task than startup waves. Across the broader suite, it reaches
76.8\% on AARRI-Bench research tasks and a 28.0 gap on mathematical data synthesis,
alongside competitive GPU-kernel and language-model-training results (Figure~1). Its artifacts extend beyond
benchmark endpoints: an optimized RWKV6 kernel was merged into the upstream Flash
Linear Attention repository, while the separately documented ACE-1 neural
processing unit (NPU) remains operator-reported pending independent
reproduction. A multi-day mathematical campaign retains one falsified route and
six proof-backed frontier updates; six autonomous paper pipelines span 254 missions
and 16 Stage rollbacks before reaching submission completion. These results show a
general harness that can revise, recover, and accumulate verified approaches without
forcing every long-horizon trajectory into a success claim.
\end{abstractbox}
