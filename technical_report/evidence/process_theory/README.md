# Process-to-Capability Supplementary Data

This directory contains the numerical material used to connect the report's
process-to-capability theory with the observed experiments.

- `theory_evidence_matrix.csv` maps each theoretical quantity to the reported
  observation, its interpretation, and the experiment needed for stronger causal
  identification.
- `formula_instantiation.csv` records the numerator, denominator, units, estimate,
  and scope of each numerical substitution discussed in the report.

The public project pages define the motivating concepts of dense intelligence,
review-gated evolution, process data, and research value. The report treats those
concepts as design hypotheses and distinguishes direct measurements from audit
indices and observational proxies.

Only aggregate values required by the paper are included. Raw runtime event streams
and private model reasoning are outside the supplementary release.
