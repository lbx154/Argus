# Process-to-capability theory evidence

This bundle maps the public Argus concepts of dense intelligence, process data,
review-gated evolution, and research value to the formal theory and empirical
evidence used in the technical report.

The official site states that Tokens are converted through reasoning, action, and
verification; trajectories update memory, skills, tools, verifiers, and routing;
research value also depends on information gain, validity, and reuse; and process
data retains states, actions, evidence, feedback, and state changes omitted from a
final artifact. The report treats these as public design concepts, not measured
facts.

## Evidence boundary

`theory_evidence_matrix.csv` freezes the current mapping from theoretical quantity
to observed evidence and decisive future experiment. Existing evidence supports
mechanism existence and descriptive trends. It does not yet estimate causal reuse
value, Reviewer sensitivity/false-acceptance rate, or a universal Token-to-intelligence
conversion constant.

`formula_instantiation.csv` records every numerator, denominator, unit, window, and
caveat used in the report's formula-instantiation table. The process-compression row is a separate
operational snapshot at 2026-07-18 10:18:56 UTC; it is not part of the earlier
mathematical claim freeze.

The compression snapshot reads the four rotated `events.jsonl*` files and
`CHECKPOINT.md` from campaign `s-9509b268`. Only aggregate byte counts are frozen
here; the large raw event stream is not copied into the report repository.
