# Mathematical Vertical Trace

This directory contains the public supplementary data for one representative
Erdős--Gyárfás research trajectory.

## Included data

- `trace.csv` records one rejected route and six subsequent theorem-frontier
  updates used by the report's vertical-trace figure and appendix table.
- `efficiency_audit.csv` reports aggregate reasoning, verification, action, and
  cost attribution for the corresponding theorem-production window.

`reviewer_verified` denotes acceptance by the Argus Reviewer within the recorded
campaign. It does not imply external peer review, publication novelty, or resolution
of the Erdős--Gyárfás conjecture. The public bundle contains claim summaries and
aggregate telemetry rather than raw model transcripts or runtime event logs.

The editable figure source is `technical_report/figures/erdos_agent_trace.html`.
