## 高频问答(10 题 · 诚实但有力)

### Q1. 你只要 25-40 万?这连我们一张支票的 1/10 都不到。你是在创业还是在要经费?
**答:** 这个小数字是我"工程师思维"的残留,不是我对天花板的判断。我重构给你:这笔钱只买一个我现在唯一不确定的答案——过程数据有没有人真金白银买。我把它设计成**一个里程碑的首笔 tranche**:两个月内做出首个付费试点、把 PMF 从 0 验证到 1,然后按种子区间放大。终局我不装小:数据墙是 2028 年前后见底的确定性需求,我做的是"自主研究+过程数据"的引擎公司,不是一个发论文的工具。我把数字报小,是怕对不起你的钱、想先诚实证明一个点,**不是不敢做大**——真格愿意按你们的区间进场、要求我放大里程碑,我接得住。
**别说:** "我们只需要这么多""不想稀释太多""学生能省着花"——任何一句坐实"没野心"。

### Q2. 过程数据 150 元/条、3 万条 = 4500 万的生意。到今天有没有人真下过一单、哪怕签过意向?
**答:** 实话:**到今天 0 成交、0 意向。** 150 元/条是我按"整条专家级多步轨迹标注"行情锚的区间(≈$21,比单步偏好比较 $0.05-5 高一到两个数量级,因为一条含大量标注目标+高技能审查),**不是成交价**,这个品类没有公开挂牌市场,我不把它说成板上钉钉。但两个可验证的真实信号:一,中电信 2025-26 确有真金白银的大模型语料+标注集中采购,招标链接现在就能发你;二,专家级人类过程数据 $70-200/小时还在涨。**我要用这笔钱验证的,就是把这个定价假设变成第一张真实订单。**
**别说:** "中电信已按 150 元/条采购过我们"——公开材料不支持,直接触雷。

### Q3. 你自己说要真卖得先换掉 gpt-5.5(违反 ToS)。那现在这 3 万条,本质上一条都不能合法卖?
**答:** 你点到最关键的工程约束,我不回避:现在这批严格说不能直接卖,得换成许可清晰的自托管开源模型(Qwen/DeepSeek)重跑+脱敏+剔 benchmark。**但我卖的不是 gpt-5.5 生成的 token,是 Argus 这套 harness『如何一步步把研究做对』的过程结构**——编排、门规则、证据/审查链、验证器,这套价值和底层哪个模型解耦。换源要重跑,但 harness 和验证器完全不变,是**可预算的工程($89 量级),不是推倒重来**;换成自托管开源模型,ToS 问题根除、单位成本可能更低。"超作者/超 Claude 3×"是真机重测的系统/数学指标,和数据生成源是两条独立的线,不受换源影响。
**别说:** "ToS 没人真管""脱敏一下现在就能卖"——低估合规=不懂商业,且和自己的诚实边界打架。

### Q4. 你这套 planner/engineer/reviewer,不就是 gpt-5.5 套个调度壳?gpt-6 出来、开源框架追上,你还剩什么?
**答:** 我同意纯调度壳会被碾平,所以我的赌注不在调度,在两个抄不走的东西。**一,防 reward-hacking 的过程约束**——冻结验证器真机重测、证据/审查链、随机化防 hardcode。连 DeepMind 的 AlphaEvolve 都得靠人类设计评估器防作弊;模型越强越会钻空子,"让结果可信"只会越来越贵,这是我花最多工程的地方,不是一段 prompt 能复制。**二,过程数据的复利**——模型越强,"怎么做对研究"的高质量轨迹越稀缺(数据墙),我是极少数能 7×24 稳定量产这种轨迹的 source。**所以模型变强对我是顺风:它降我的生成成本,同时抬高我这条护城河的价值。**
**别说:** 空泛的"我们 prompt 工程很难复制";或盲目轻视大厂却拿不出差异化。

### Q5. "超作者""比 Claude Code 高 3 倍""AARRI-Bench 最优"——那个星号是什么?是你们自己造的 benchmark、自己打的分吗?

**别说:** 把"顶会门槛"说成"已中顶会",把内部对比说成"第三方认证"——任何夸大瞬间引爆诚信雷。

### Q6. 你的文档里写着完成一篇是"4 篇成 1 篇"的稀有事件。产能上限卡在哪?怎么把稀有事件规模化?

**别说:** "产量不是问题""很快就能放量"——和自己公开的数据打架。

**别说:** "毛利 80%/已盈利";或对 runway 含糊——真格追得很细。
