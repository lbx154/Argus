# 网页试用质量验收 · 2026-09-15

本轮使用真实浏览器、隔离的 HTTP 服务和少量真实 Argus-Pi 调用。高并发场景使用确定性执行器，不向模型供应商发送压力流量。没有冒充真人访谈，也没有把模拟执行记成真实任务质量。

## 发现和修复

| 问题 | 修复后的行为 |
| --- | --- |
| Pi 逐轮用量没有进入运行中预算监控 | 读取 assistant `message_end`；忽略重复的 `turn_end`/`agent_end`，新用量立即触发下一次预算检查 |
| 订阅请求显示低美元费用时，缺少独立的 token 保护 | 新增全站每日 token 上限，合并已结算与在途用量；缓存只计一次，保留未知终态前已观察到的用量 |
| 不同项目/Pi 调用没有共同的进程并发限制 | 可配置跨后端、跨项目的进程槽位；占满时启动前拒绝，进程死亡后由操作系统释放 |
| 网页请求可能大量占用线程等待 Manager | 最多 8 个在途消息、每个项目 1 个；重复提交返回 409，容量不足返回带 Retry-After 的 503；停止接口保持独立 |
| 地图发送后遇到网络故障，恢复的草稿仍被折叠隐藏 | 异步失败后重新展开输入框，草稿可以直接修正或重试 |
| 超长文本和请求体缺少整体约束 | 消息 32,000 字符，JSON 请求 256 KiB，上传请求体 26 MiB；分块传输同样计数，错误不回显原文；前端保留超长草稿 |
| 预算保存失败却改变了进程内配置 | 先完整验证，再写持久配置，成功后更新环境；失败不会留下虚假的预算偏好记录 |
| 任务的最后一次小修补被用作总体摘要 | 当前任务显示任务级说明，局部执行记录保留在历史中；不重复显示相同说明 |
| 已取消的单 agent 卡片显示“状态未知”或“已暂停” | 地图、步骤和通用状态标签明确显示“已取消” |
| 成果卡重复整段回复，并直接打印 Markdown 和内部文件链接 | 对话中的成果卡只提供完成状态和打开成果操作；通知及成果说明使用已有的安全 Markdown 展示 |
| 访谈选项混合了计算口径和展示方式 | 要求围绕同一关键决策给出互斥选项；信息足够时直接准备执行定义 |
| vertical 的验证容易只覆盖首个样例 | 日常建流程任务要求冻结候选、测试不同输入、保存失败反例，并在修复后回归反例及未受影响的案例 |

## 实测

- 修复后后端范围回归：1,450 项，1,448 通过、2 跳过；包括 WebAPI、费用、额度、取消、附件、缓存、Pi、预算恢复、架构和提示词预算。
- 完整网页测试及 Web/TUI 构建通过。Python 类型检查没有新增诊断；既有 1,283 项类型诊断仍是技术债。
- 真实 TCP：已有一个请求在执行时突发 64 次提交，全部 409，未重复执行；P95 195 ms，停止请求约 6 ms。
- 同时 64 路 snapshot 读取全部 200，P95 334 ms，最大 350 ms。此结果来自本机隔离 fixture，不代表公网服务容量保证。
- 跨项目测试：8 条慢请求加 48 条溢出请求，溢出被拒绝，取消与元数据读取仍可完成。
- 进程槽位测试：24 次竞争最多放行 2 个，另有真实子进程退出后释放测试。
- 真实 Pi：上限 1,000 tokens，第一条用量回执记录 1,005 后中止，下一次调用启动前拒绝；无遗留 reservation，输入文件未改变。
- 浏览器验证包含刷新后找回执行、停止、再次提交、完成后 Atlas 记录，以及页面更新通知。
- 额外真实用户任务：通过浏览器上传 12 行销售 CSV，直接由 Argus 处理；约 50 秒交付两个 CSV。CNY 收入/退款/净额为 150/20/130，USD 为 42.5/5/37.5；6 个重复或无效记录及其原文件行号均与独立计算一致。未创建 Team，也没有多问流程设计问题。

预算并不是模型供应商的订阅余额。Token 按现有规范化账本计输入（含缓存）、输出与单列的 reasoning 用量。Pi/Copilot 的在途保护依赖供应商回执，其他后端在结算后的下一次调用检查；一个尚未返回回执的请求仍可能超过剩余额度。跨日沿用现有账本的结算日规则。

## 访谈和泛化

真实模型为 `gpt-5.6-sol`，通过 Argus 的运行入口调用固定的 Pi 版本；各案例使用隔离项目，不派发真实生产任务。

访谈覆盖销售 CSV、缺少代码/GPU 的论文复现、日期民俗解读、规格已完整、只询问按钮含义、要求编造财报缺失值等 6 类场景。已完整的规格进入 PREPARE；未同意创建流程的提问保持 REPLY；缺失财务数据没有被伪造。

CSV 的首次选项混合了财务口径和展示方式。修正规则后的同题复测给出“按原币种分别汇总／按交易日汇率折算／按期末汇率折算”，三个选项回答同一个会影响正确性的问题。这个小样本可以发现缺陷，不能给出总体访谈准确率。

| 独立案例 | 原始版本 | 修正候选 |

## 卡片审视原则与适用范围

地图任务卡回答“做什么、当前状态是什么”；历史记录解释发生过什么；决策卡只承载用户必须决定的分歧；技能库说明可复用能力；成果入口打开实际交付；费用只展示可核验的消费信息。空占位、重复说明、局部记录冒充总体结论都不应进入主卡片。

这仍是共享访问身份的试用站。全站额度保护不能替代用户身份、项目权限隔离和每用户配额。长时间 soak、真实多人容量、第三方模型故障和不同任务领域的质量评估仍需持续进行；这次验收不能证明“没有 bug”或达到完整多租户生产标准。
