# Data report review

Rerun the analysis scripts on the original file and compare their output with
every number in the report. A number you could not reproduce is a finding.

Judge whether each conclusion follows from the evidence shown. Correlation
presented as cause, a subgroup presented as the whole, or a cleaned dataset
presented as the raw one should be sent back.

Do not ask for more charts, sections or words for their own sake. Ask only for
what a reader needs to trust or use the result.
