项目简介。Argus 是一个全自主研究 agent：在仅给定研究目标与运行环境约束的条件下，无需人工逐步介入，自主完成从选题、文献调研、实验设计与执行、结果分析到产出可复现结果的完整研究闭环。其特点主要体现在三个方面：

（1）在前沿自动研究基准上已展现出较强能力。系统以同一套引擎驱动，目前已应用于 GPU kernel 性能优化、大模型训练脚本与训练基础设施加速、量化因子挖掘，以及端到端论文撰写等多类任务。其中，在 KernelBench 这一前沿自动研究基准上已取得有竞争力的结果（已在其子集上超过 Recursive AI 的公开结果）；无论是面向硬件的 kernel 优化，还是面向软件与典型训练基础设施（如 nanochat 类）的优化，系统均体现出较强的优化能力，表明我们在自动研究方向上已迈出关键一步。各任务均以客观、可量化的硬指标为评价标准，要求在同等环境下复现并超越公认强基线；在此基础上，评测的公平性也得到了较好的保障。

（2）以长时连续自主运行为核心能力，并已形成相应的解决方案。我们将上述问题统称为“密集智能任务”，即需要连续、高密度地进行非平凡决策、通常跨越数日方能收敛的开放问题；其真正的难点不在于完成某一次判断，而在于让系统在数天、成千上万轮的连续运行中始终保持有效产出而不退化。为此，系统采用多角色协作架构：规划、执行、评审等角色分工协同，由评审角色独立判定每一步是否达标并给出下一步，规划角色在任务完成或受阻时自动续排与拆解，使整个工作流自我驱动、无需人为逐步介入。针对长时间运行中普遍存在的“记忆膨胀导致能力退化”问题，系统对各工作单元的上下文进行有界管理与结构化交接，使其无论运行多久都不致因历史累积而退化或重复劳动，并配有对空转、停滞与死循环的自动检测与恢复。由此，系统可在完全无人干预下持续运行一周以上，不断自我迭代、自然生长。

（3）具备自进化能力。研究中遇到的许多问题是分布外（out-of-distribution）的，需要特定领域的专业知识方能求解——基础模型并不“天生”掌握某一具体硬件架构的访存与对齐特性、某一训练栈的工程技巧，或某一市场的因子构造方法。系统不预设自身已具备这些能力，而是将“不会”本身视作首个待解的子问题：自主调研该类问题的既有解法、在真实环境中验证，并把其中确实奏效的经验沉淀为可复用、可累积的能力；任务的成功与失败都会反馈到这一能力积累中，用于改进后续运行。其效果是，针对同一类问题反复推进时，系统掌握的专业经验持续累积、表现随之提升，而不会停留在基础模型单次推理所能达到的上限，也不依赖简单更换更大规模的基础模型。
