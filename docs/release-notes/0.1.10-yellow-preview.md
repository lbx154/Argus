# Argus 0.1.10 — warm-yellow local preview revision

This local manual-test candidate is based on the previous preview source at
`7baf0209ff67468cfd2806dacf6419bc0ca631fd`, which itself synchronizes the user's
local `D:\Argus\argus-skill` commit `252610599e707a886d6a9d482c630db9e15887a1`.
Version remains 0.1.10 because this candidate has not been published.

## Requested visual change

- The light startup-animation page uses the existing cockpit's pale warm-yellow
  color `#f7f3e8`, rather than the old cold `#f9fafb` surface.
- Native initial window paint, title caption/border, menu and startup background
  use the same warm surface; settings cards use a related ivory `#fcfaf4`.
- Blue launcher accents are replaced by the cockpit's text-safe gold and warm
  gold. Completed-step foregrounds keep at least 4.5:1 contrast.
- Dark mode retains a dark surface, using the cockpit's existing `#0c0c0d` and
  gold accents rather than forcing a light-yellow page onto a dark preference.
- The original eye SVG, pupil/highlight geometry, timing, native visibility
  accounting, startup/reconnect behavior and backend lifetime logic are unchanged.

## Verification and scope

Palette regression checks compare the desktop colors to the canonical cockpit
CSS, validate the first native background/configuration, and check contrast.
Targeted browser shell tests cover onboarding, the visible animated cold start,
recovery and saved dark preference. Their screenshots are browser-based evidence,
not a claim of native Windows Toast or full production-cockpit GUI acceptance.
The frozen backend and actual packaged-host startup/identity/short health check
remain required before the manual preview ZIP is created.

Full navigation GUI regression, paid agent tasks, Windows Toast, fault injection,
30-minute soak, signed installer and install/upgrade acceptance remain separate
pending checks. No signing material, user account configuration or production
profile is copied. Automatic updating is disabled in the preview.

## Use and cleanup boundary

Extract the entire ZIP and run `Argus.exe`, or use the supplied local launcher.
The existing preview-only profile is `%APPDATA%\argus-desktop-preview-integration-20260913\`.
It is separate from production, but shared with older previews using the same
identifier. Explicitly quit an older preview first; never run two versions
against one project workspace. Window close hides to tray; use **Stop local
backend and quit** to exit.

The old preview is retained while this revision is built and validated. Cleanup
is limited to the previous delivered preview ZIP, its duplicate build ZIP,
extracted preview and old launcher after the exact deletion scope is confirmed.
The user's source checkout, historical official releases, build evidence and
AppData/projects are outside that deletion scope.
GitHub upload remains blocked until the user reviews and approves this revision.
