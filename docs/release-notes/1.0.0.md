# Argus 1.0.0 — Windows · TypeScript 内核与四角色独立 CLI

## 升级前必读

**这是一次内核切换，不是旧 Python 项目的无损续接更新。**

- 旧项目/历史的自动迁移与续接尚未实现；新内核不会主动删除旧数据，但不会直接显示或接管旧项目。
- 旧 Python 内核默认使用 `~/.argus-skill`（或 `ARGUS_SKILL_HOME`）；1.0.0 默认使用 `~/.argus`（或 `ARGUS_HOME`）。不要把两个内核指向同一状态根，也不要让两个版本同时操作同一个工作目录。
- **需要继续旧项目的 0.1.10 用户请暂缓升级。** 安装前自行备份旧状态根和项目工作目录；桌面设置的兼容读取不代表项目历史已经迁移。
- 0.1.10 → 1.0.0 的隔离安装/卸载/升级全流程尚未验收，不能把构建、签名或原生窗口验证当作升级验证。
- 本次在这些限制已经披露后，由发布负责人明确批准发布。它们没有被标成“已通过”。

## 本版变化

- Windows 桌面改用 TypeScript 内核，内置 Node 运行时及许可证，桌面运行不依赖 Python。
- 经理、规划者、工程师、审阅者分别选择 Agent CLI、该 CLI 的真实模型及推理强度；实际调用和会话按角色独立调度，不借用其他角色的模型。
- 模型选择只显示本机可发现的 CLI，不再把所有支持项列出后标“已安装/未安装”。发现可执行文件不代表鉴权成功。
- 每条角色路线独立查询费率、记录用量和费用来源，显示 CLI 声明价、公开参考价或未知。公共参考目录来自 `models.dev`；订阅/额度或代理账单可能不同。未知价格不按零元处理。
- 修正 DSH 输入/缓存用量的归一化；Codex 按实际请求模型记录价格来源，不再静默套用一个全局静态单价。
- 补齐支持的增量消息显示和不含提示词的阶段耗时记录。交接仍必须完整校验，不把半截文字判作完成；不承诺远端推理固定提速。
- 首次设置、菜单、侧栏、对话、地图、工作台及模型弹窗统一暖黄色/金色主题。
- Windows 原生最小化、最大化、关闭所在标题栏同步主题；保留原生按钮和窗口行为。已在 Windows 11 的真实隔离窗口验证浅色、深色、最大化、最小化与恢复。

## CLI 兼容性：协议测试与真实账号分开

| CLI | 当前验收结论 |
|---|---|
| Pi | 四角色有真实成功记录，支持原生模型目录及自定义提供商 |
| DSH | 经理、工程师、审阅者有真实成功记录；规划者仍以协议回归为主 |
| Codex | 工程师有真实成功记录；经理后续遇到外部服务路由失败/超时 |
| Claude Code | 原生模型目录成功；此前真实调用返回 401，尚未取得新的成功证明 |
| Copilot / Cursor / OpenCode / Grok / Qoder | 已接入并有协议/调度回归，本轮没有真实账号通过证明 |

九种 CLI 的 81 个有向配对属于调度夹具回归，不是 81 次真实账号调用。新增流式行为的协议测试不等于新增真实账号验收。不会盲目重复失败的付费调用。

## 验证范围与已知缺口

- 最近完整前端回归：137 个测试文件、1114 项通过。
- 核心角色/模型/价格/流式/协议专项：237 项，其中 229 通过、8 个平台项跳过。
- Rust 桌面：88 项通过，2 个隔离子进程测试入口按设计 ignored。
- 预览身份、发布签名和复制校验有独立回归；正式三件套还必须由原 updater 公钥验签通过才能上传。
- 旧全量 workspace 曾有 5 项 Windows 符号链接权限失败；旧 Python UI 夹具仍有未完成的回归修复。以上专项结果不代表全量测试全绿。
- Windows 10 的原生 DWM 配色能力取决于系统支持；本轮标题栏像素验收环境是 Windows 11，不能冒充全部 Windows 版本已验收。
- 用户最后验收的是本地预览；未把该免安装预览改名为正式安装器。正式安装器另由 CI 从发布源码构建并使用原签名体系签名。

## 下载与信任

本 Release 只提供 Windows x64 三件套：

1. `Argus-1.0.0-setup.exe` — NSIS 安装器。
2. `Argus-1.0.0-setup.exe.sig` — Tauri updater 验签文件。
3. `latest.json` — Windows 更新元数据。

保留正式应用标识 `cn.argusbot.desktop` 和原 updater 公钥。签名由原发布流程的 CI 安全配置提供，不生成替代密钥。
`.exe.sig` 是 updater 签名，不是 Windows Authenticode 证书；系统仍可能显示发布者/信誉提示。

旧版更新依然需要用户在应用内确认安装，不是远程强制或静默安装。发布后在线元数据/下载校验也不等于已在用户机器执行安装升级。
