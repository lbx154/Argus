# Argus 0.1.10 Windows local preview

Status: local acceptance candidate only. No GitHub push, release upload, signing,
installer run, or production profile migration is authorized by this build.

## Source

The candidate is based on the user's local `D:\Argus\argus-skill` checkout at
`252610599e707a886d6a9d482c630db9e15887a1`. Product source is taken from that
commit, not from the older installed/frozen backend or another remote branch.
The Python runtime, frontend packages and locks, desktop npm/Rust/Tauri metadata,
and plugin metadata use version **0.1.10**, above the existing 0.1.9 release.
The Web/TUI bundles and release identity are regenerated together before freezing.
The release generator now retains the reviewed source identity across artifact-only
commits. Byte-level Git diffs prevent same-length source edits from being mistaken
for an unchanged source; focused tests cover rebuilds, edits, new inputs and versions.
Editable build configuration names the repository root explicitly so Windows
bootstrap does not auto-detect imports through npm workspace links. This changes
the build setup, not the frozen application's role or workflow behavior.
Isolated Windows builds rebuild Web assets into a clean generated directory;
live/hosted builds still preserve historical chunks for already-open tabs.
Native adapter tests use a short, isolated temporary directory to respect the
scientific bridge's 80-character path limit without relying on CI-only variables.
Windows regression fixtures write explicit LF when asserting exact LF content;
HTML path-confinement cases run without symlink privileges, with additional
symlink cases capability-gated rather than failing at fixture creation.
Desktop synthetic session fixtures now read the canonical shared protocol JSON
instead of parsing constants removed from the frontend wrapper.

This delivery uses the explicit manual-test preview path. Minimum real packaged
startup/identity/health checks are required; full GUI automation (whose old
navigation selectors need updating), native Toast, fault injection and the
30-minute soak are not certified by this package. The failed GUI run is retained
as local evidence, not relabeled as passing.

Recent source changes included in this synchronization include:

- Chat messages can contain up to one million characters.
- Team startup no longer waits for the removed backend-readiness probe gate.
- Inline images and links prefixed with `workspace/` resolve against the project.
- Trial tenant identity records project-relative paths rather than `/tenant/workspace`.

These are source inclusions, not claims of paid-model or end-to-end research
validation. The actual acceptance evidence is delivered with the preview.

## Preview use

Extract the entire ZIP into a new directory, then run `Argus.exe`. Do not move
only the EXE. Windows 10/11 x64 and Microsoft WebView2 Runtime are required;
Python and Node.js are bundled/not required for launching the frozen runtime.
Real agent work still requires an explicitly chosen, authenticated Agent CLI
or an independently provided trial invitation.

The existing preview-only profile is retained:
`%APPDATA%\argus-desktop-preview-integration-20260913\`, port 18799.
It is separate from the production profile, but shared with older previews using
that identifier. Explicitly quit an older preview before opening this one; do
not run both against the same project workspace. No old files or profiles are
cleared automatically.

Ordinary window close hides to the tray. Use **Stop local backend and quit**
to actually exit. The preview disables automatic-update checks and installation
at compile time. It contains no signing material or account configuration.
