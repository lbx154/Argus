# Argus repaired state-machine figures

Publication-oriented, fully editable state-machine figures generated after the
July 20, 2026 liveness hardening pass.

## Decks

- `argus-state-machine-cn.pptx` — Chinese, two slides.
- `argus-state-machine-en.pptx` — English, two slides.

Each language directory contains the native SVG page sources, design
specification, and speaker notes:

1. Repaired multi-agent state machine and explicit exit edges.
2. Liveness safeguard atlas mapping the former P0/P1/P2 risks to implemented
   guards and safe terminal states.

The PPTX files use native DrawingML shapes and remain editable in PowerPoint.
