# 01_state_machine

This figure shows the repaired production state machine rather than the earlier risk diagnosis. Ordinary Planner batches and replacement plans are cycle-checked and committed atomically, while both next-pending inspection and actual claiming perform the same dependency reconciliation, so legacy cycles, missing dependencies, and failed dependencies reach an explicit skipped state instead of masquerading as an empty queue. The Engineer–Reviewer same-scope loop remains intact, but every scope-changing replan carries a plan identity and version, commits by compare-and-swap, and fails closed after three replacement attempts produce nothing usable. Pauses, operator answers, and upgrades now have separate exits: externally recoverable pauses start a fresh attempt, operator answers rewire every live downstream dependency, upgrade requests return immediately while healthy long experiments finish at a natural boundary, and a new intent reopens a completed workspace stage.

# 02_deadlock_atlas

The second figure maps each of the thirteen former liveness risks to its implemented guard and terminal outcome. The six P0 paths are closed by pre-commit cycle rejection, read-time SCC termination, versioned replacement, a three-strike circuit breaker, automatic wake-up, and atomic dependency rewiring; the five P1 stalls are closed by terminal HOLD handling, nonblocking upgrade polling, conservative unpriced-cost holds, bounded Manager feedback, and context-aware deduplication. Concurrency now follows one pipeline-then-session lock order, and Planner no-runner or exception paths back off from fifteen to three hundred seconds rather than entering a retry storm. Verification covered the expanded life, Manager, and daemon suites, twenty consecutive stress rounds for concurrent claims, concurrent answers, and filtered replans, plus all terminal and web frontend tests, with no duplicate claim, duplicate continuation, or non-terminating state component observed.
