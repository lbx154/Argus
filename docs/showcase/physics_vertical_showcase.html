01 · Positioning

不是又一个任务执行器Generic Research Vertical vs. Physics Vertical

大多数科研 AI 停留在文献搜索、摘要生成、代码辅助。普通的 research vertical 更像一个泛化任务执行器； Physics Vertical 强迫模型回答物理研究真正要回答的问题——并用 gate 把这些问题变成不可跳过的验收标准。

Generic Research Vertical

普通研究垂育

PlanRunDraftReviewSubmit

一个泛化的任务执行器：把目标拆成步骤、跑脚本、写文档、提交。它不强制追问物理与证据是否自洽。

  • 大致把任务做完即可
  • 文献只是“检索到”，不要求读透
  • “观察到现象”常被当作结论
  • novelty 靠语言判断，可被包装
VS
Argus Physics Vertical

物理科研垂育

ScopeModelExecuteReviewManuscript

同样五步，但每一步都被物理研究协议锁定。系统必须把大词落成方程、把结论落成可复现证据。

  • 具体的物理系统与哈密顿量是什么？
  • 已有文献做到了哪一步，还差什么？
  • 变量 / 边界条件 / 近似条件是什么？
  • 数值证据在哪里，能否复现？
  • claim 是否真的新，还是 already-known？
  • manuscript 是否让 claim 与 evidence 对齐？

03 · Stage-Entry Contracts

开工前就把 gate 压进 promptScientific Protocol Lock

每一阶段开始前，系统会把这一阶段的 hard requirements 写进 agent 的任务契约里。 不是最后才检查，而是在开工前就把验收标准锁死——像一份「mission contract」。

◆ SCOPE · Entry Contract🔒 LITERATURE LOCK
▹必须生成 PRIOR_WORK_MATRIX.csv，含 gate schema 要求的字段
▹至少 8 篇直接相关 prior work，至少 6 篇 full-text read
▹必须区分 known / gap / possible novelty
▹RESEARCH_BRIEF 必须命名 method / baseline / target metric / thesis
⛔ Literature gate 未通过前，不得使用 original-research 框架宣称创新。
◆ EXECUTE · Entry Contract🔒 EVIDENCE LOCK
▹必须生成 NUMERICAL_STUDY_PLAN.csv 并逐条对应 claim
▹必须保存 scripts / data / evidence 与 manifest hash
▹robust claim 必须附 robustness check
▹phase diagram / universal claim 必须附 parameter scan
⛔ 没有可复现证据支撑的 claim，不得进入 review。

这套机制把「稍后再审」变成「开工即受约束」。Agent 从第一行动作起，就在一份被写死的科学协议下工作， gate 标准不是事后的检查表，而是任务本身的一部分。

在 original-research-required 模式下，Argus 不能轻易说「我做了个 benchmark，完成」。 它必须走完一整套 novelty-seeking loop，最后才决定：这里到底有没有 original claim。

决定是否存在 original claim

✓ ORIGINAL CLAIM — 本样例结果
novelty 足够 → 进入 manuscript 交付。本样例被 Paper-Type gate 判定为 “original research article candidate”（confidence: medium），并附完整 known-vs-new 分解。

06 · Gates / Firewalls

六道门控，各防一种过度宣称What Each Gate Prevents

Gate 不是装饰，每一道都精确地封堵一种科研中最常见的“过度宣称”路径。全部六道在本样例中 PASS。

PASS
Literature

文献门控

防止没读文献就说创新。要求 claim 有 mapped closest prior work。

PASS
Theory

理论门控

防止没有模型、没有边界条件、没有近似条件就往下走。

PASS
Numerical

数值门控

防止只有玩具数值，却声称 robustness / universal / phase diagram。

PASS
Novelty

创新门控

防止把 known result 重新包装成 original result。

PASS
Paper Type

论文类型门控

防止 evidence 只够 benchmark，却硬说 original paper。

TERMINAL ✓
Manuscript

论文硬门控

防止最后论文缺图、缺引用、claim 无证据、paper type 与 evidence 不匹配。

Manuscript gate 是 terminal hard gate。 Manager 不能仅凭 reviewer 的文字叙述就宣布 project_done——必须通过确定性 verifier：manuscript check --layer all（original-research-required 模式） 返回 satisfied, exit 0。本样例三层 source / paper / all 全部通过。

◆ The problem

GBZ 看起来数学上很健康，却错过了物理边界响应

传统 rational-approximant GBZ baseline 在采样的有限体积里是稳定的、integer-like、singular-gap resolved——所有内部健康检查都通过。 但它在 η₀ 扇区系统性地错过了 positive open-boundary / cylinder 标签，positive fraction 恒为 0。

◆ The candidate diagnostic

SVEPη₀ 读出了 GBZ 看不见的低奇异响应边界极化

Argus 提出 SVEPη₀：基于 A₀ = U − I 的最小右奇异向量的 edge polarization score。 它在 held-out validation、reduced q-scaling、phason-flow checks 上恢复了 η₀ open-label 预测。

GBZ looked mathematically healthy, but physically missed the edge response.
SVEPη₀ reads the low-singular-response edge polarization that the rational-supercell GBZ baseline cannot see.
