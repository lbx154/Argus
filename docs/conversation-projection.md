# 对话、角色记录和项目状态的服务端投影

服务端首次读取完整事件记录，之后只折叠新增的完整行。投影留在内存；项目当前状态仍由 `project.json` 提供，事件记录仍保存在 `events.jsonl`。

对话按操作者消息、经理回复与简报、团队的问题和任务行输出。交付卡片跟随经理交付的那一行。任务只有一行，其位置随最近一次状态变化更新，工具步骤进入角色日志。回答时，问题和答案整组移到回答的位置，并同时更新两行的版本；问题保留最初的时间戳。这样，即使旧问题未在当前页中，实时增量也带回完整问答，刷新仍能读到新回答。新答案记录问题标识，支持同一角色在不同任务上同时提问、逆序回答。读取旧记录时，仅在收信角色唯一对应一个待答问题时关联，无法确定的问题不猜配。

角色日志从最近一条操作者消息起计算，回答也开启一轮。首次读取和实时增量使用同一份折叠结果。角色面板直接显示服务端提供的本轮记录，生命周期公告不归给工程师。跨轮最后一句话、旧时间线重排、任务回报模板与过程回填组件已删除。

项目快照和项目列表都带服务端给出的状态及中英文文案。对话页顶栏、侧栏和实时地图原样使用该文案。停止优先显示“已停止：2 个任务暂停”；待答问题显示“等你回答 1 个问题”，还有任务执行时附带实际执行中的任务数。

## 接口

| 入口 | 返回内容 |
| --- | --- |
| `GET /api/projects/:id/conversation?limit=30&before=…` | 按行分页的 `rows`、更早一页的 `before` 和记录游标 `cursor`。`limit` 为 1–120；分页边界同时保留问题与答案。 |
| `GET /api/projects/:id/stream?view=rows&after=…` | 变更的对话行、本轮新增角色记录和游标；重连接收 `Last-Event-ID`。 |
| 项目快照 | 本轮 `role_events`、角色运行信息和统一的 `work_status`。 |
| 项目列表 | 每个项目的同一份 `work_status`。 |

页面按稳定行标识替换增量行，再使用服务端给出的顺序。主对话与地图对话共用同一份分页数据、加载状态和回调，向上滚动或点击“更早的对话”加载更早的页，并保持阅读位置。旧 `/transcript` 接口和前端对应的合并路径已移除。

## 验证记录（2026-10-29）

回放基线是仓库中已脱敏的真实三任务项目，共 104 条事件。测试在其后追加 140 条取自该记录的命令步骤，形成 244 条事件的受控长尾。三个任务的完成事件均落在最后 120 条之外；逐行实时读取、完整重读和按行分页保留相同的任务行与本轮角色日志。另有实际 HTTP/SSE 测试走完提问、回答、审阅和交付，核对实时结果与刷新结果相同，并测试同角色多问题逆序回答。

任务所给的 `sample/events.jsonl` 在本次工作区中不存在。因此上述验证使用真实记录的受控加长回放，没有验证所述 2,000 多条事件的 RL 项目原件。

从构建后的 CLI 启动独立状态目录，在 Chromium 中验证了：

- 长尾项目刷新前后对话文本相同，三个已完成任务行保留。
- 决策框提交的“42”紧接“工程师问：这轮实验使用哪个种子？”，完成任务行在回答后；刷新结果相同。
- 20 个脚本后端任务的项目，初次取 30 行，向上滚动再取两页，能读到第一条消息和全部 20 个任务行。
- 停止两个实际挂起的脚本后端任务后，顶栏、侧栏、地图和团队状态都显示“已停止：2 个任务暂停”。

以上浏览器场景没有页面脚本错误。截图、浏览器断言和独立项目记录保存在本地 `.integration/rows/`；没有纳入提交。

退回修复增加了超出当前页的场景。实际 HTTP/SSE 回归先让工程师提问，再追加 20 轮经理对话，确认当前 30 行不含问题；回答后验证增量、断线重连和刷新首页均包含相邻的问答，并确认向上分页不重复。该测试在修复前因增量缺少问题行而失败。

Chromium 中重走了相同操作，从决策框提交“424242”，确认问答在最近一轮经理对话之后相邻出现；清空浏览器的查询缓存后刷新，并在全新浏览器上下文中重新读取，新的 30 行仍保留完整问答。另一个 20 任务项目直接打开地图对话，初始显示 10 个任务行；滚到顶部发出两次带 `before` 的分页请求后显示全部 20 个。切回主对话也保留这 20 个任务，无需重新加载历史。这两条路径没有页面脚本错误；截图与断言保存在 `.integration/rows-return/`。

检查命令：仓库根目录 `npm run check`；Web 目录 `npm run typecheck`、`npm test`、`npm run build`；`npm run web -w packages/core`。容器安装检查已尝试，因 `/var/run/docker.sock` 不存在而未完成；没有启动或替换系统 Docker 服务。
