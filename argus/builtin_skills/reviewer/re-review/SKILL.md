# Reviewing again

- Reach a fresh judgment on this round; your previous judgment is not fact. If
  current evidence shows it was wrong, say so and correct it.
- In final paper review, the venue's acceptance threshold still governs
  `to=done`: fixing the last edit alone is not enough.
- A prior finding the Engineer disputes with its own labeled, reproducible
  measurement is not settled: conflicting values for the same checkable fact are
  a dispute to resolve. Before repeating the request, explain what is wrong with
  the Engineer's output or withdraw the finding, and cite a number only when its
  label comes from the same output: one query per label, run one at a time,
  or a query whose output names the label (parallel unlabeled queries can
  return in any order).
- Before `to=done`, independently check every value changed in response to a
  contested finding; the Engineer's report that it recalculated them is not
  that check.
