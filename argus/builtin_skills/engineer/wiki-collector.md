# Semantic Wiki Research

## When to use

Use when the current mission identifies a concrete declarative knowledge gap and
primary-source research is warranted.

## Workflow

1. Read the Wiki root path and `INDEX.md`.
2. Search existing semantic pages before external research.
3. Derive a small set of concrete queries from the actual gap.
4. Fetch real primary sources or repository artifacts; never fabricate citations.
5. If evidence supports durable knowledge, create or refine one semantically named
   page under `pages/`.
6. Keep exactly `title` and `description` frontmatter followed by Markdown.
7. Cite real URLs or artifact paths in the body where useful.
8. Consider the optional `Insight` guidance below only when the evidence supports
   more than a factual summary.
9. Add or update one concise semantic link in `INDEX.md`.
10. If the research adds nothing durable, make no Wiki edit.

Do not create a source database, tags, statuses, run cards, generated IDs, or
per-source placeholder pages.

## Optional Insight

Keep the main content factual and source-backed. A separate `## Insight` section
may capture an interpretation, non-obvious pattern, abstraction, transferable
lesson, or hypothesis. Explicitly label it as an interpretation, not an
established fact. Omit the section if evidence is insufficient or the prose would
merely repeat the summary; an empty heading or generic lesson adds no knowledge.

Where useful, explain the motivating observations with source links, the proposed
mechanism, its likely scope, possible transfer, and assumptions or counterexamples.
Use prose and optional subheadings rather than mandatory fields or confidence
scores. Several insights are welcome when each is independently useful.

Search existing page bodies and related projects available to you before claiming
novelty or transfer. Cross-link supporting or contradictory pages, including
`#insight` anchors when citing their interpretations. Describe a cross-project
connection as a hypothesis until evidence supports it. Keep descriptions and
INDEX entries equally clear about that uncertainty. As evidence changes, strengthen,
narrow, challenge, or withdraw the interpretation while preserving valid facts.
