# Math Vertical

## 目标

建设面向数学猜想、证明和开放研究问题的 vertical。它既提供研究 workflow，也内置
高质量、可迁移的数学种子，使后续任务能够在真实轨迹中持续进化。

## 初始种子

系统性搜集并结构化整理：

- Lean 4、Mathlib、定义建模、定理检索、常用 tactic、证明分解、编译反馈，以及
  自然语言证明到形式化证明的转换方法。
- 直接证明、反证法、归纳法、构造法、极值法、不变量、概率法、对角化、局部到
  整体和反例搜索等自然语言证明方法。
- 代数、分析、组合、数论、概率、几何、拓扑和优化等领域的常用知识、典型技巧、
  计算实验和文献检索方法。
- 同时展示自然语言证明、Lean 形式化、关键策略、失败尝试和修正过程的优质范例。

种子应有来源、版本、适用范围和可复现证据。Lean 示例应实际编译；自然语言证明
应保留完整前提和论证。优先保留能迁移到新问题的方法，不无差别复制大段资料。

## 研究能力

让 agent 自主完成问题形式化、背景检索、例子和反例探索、计算实验、证明构造、
Lean 形式化、编译检查、独立审查与结果整理。根据问题动态选择路径，不把这些步骤
写成每题必走的固定流水线。

Lean 编译是重要证据，但不能证明定义忠实、前提有意义或结论有研究价值。自然语言
证明与形式化证明应相互校验，最终由 reviewer 结合实际 artifact 和轨迹判断。

## 进化与完整性

把可迁移方法写入 Skill，把数学事实、定义、文献和实验结论写入 Wiki，并遵循
[persistent-evolution.md](persistent-evolution.md) 的持久化、结构化和渐进式披露原则。

严格隔离评测数据。目标 benchmark 的题目、答案、证明及针对性变体不得进入种子、
Skill 或 Wiki，也不得把记忆命中包装成数学能力提升。
