ORCA is proprietary software. Do not automate download, redistribute binaries,
or assume a license. Use only an installation the operator or facility has
already authorized; verify current terms at <https://www.faccts.de/orca/>.

Probe `orca` with the installed version and a tiny operator-approved input.
Retain the exact input, geometry, charge/multiplicity, method, basis/ECP,
auxiliary bases, dispersion/solvation settings, convergence controls, output,
restart files, executable version, and environment.

Check SCF/geometry convergence and warnings explicitly. Cross-method comparisons
require consistent structures, reference states, and corrections.
