# 平水韵字表 (pingshui.json) — provenance

`pingshui.json` is the 平水韵 (Píngshuǐ rhyme) character table: each Chinese
character maps to one or more readings, each `{rhyme, section, tone}` (平/仄).
It is the **data layer** that makes `prosody.py`'s checks reproducible — the
validator looks a character up in this table rather than "remembering" whether a
line is metrical.

## Source / attribution

Adapted (unmodified data) from the local `classical-poetry-prototype`
(`classical-chinese-poetry/data/pingshui.json`, generated by that prototype's
`scripts/build_rhyme_map.py`). Migrated here so the `classical_poetry` vertical
carries its own reproducible rhyme table and does not depend on the external
prototype at run time.

- 8232 character entries; multi-tone characters (多音字) carry multiple readings
  and are treated as 两可 (either), never false-flagged, by `prosody.py`.
- A character absent from the table is reported as `?` (undecidable) — never
  silently treated as an error.

This is a rights-neutral lexical reference table (rhyme categories of Chinese
characters), not a corpus of copyrighted poems.
