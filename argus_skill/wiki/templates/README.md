# .autors/<project>/wiki

Per-project idea wiki. See `docs/IDEA_WIKI_DESIGN.md` in the argus-skill
repo for the full design.

## Layout

- `sources/` -- immutable raw evidence (papers, repos, runs)
- `pages/` -- synthesized judgment cards (technique / conflict / pattern)
- `queries/` -- derived, regenerated by `argus_skill.wiki.index`
- `data/` -- schema + controlled vocab
- `scripts/` -- local validators

## Promotion

`status` is a frontmatter field on each `pages/*` card:

- `scratch`: newly noticed; not yet structured-enough to act on
- `candidate`: structured, sourced, reviewed once
- `stable`: reviewer-certified; planner may act on it

The reviewer is the only promoter.

## Auto-collection

Pages and sources are written as a side-effect of normal missions. There
is no crawler. If `pages/` looks empty after a mission, the reviewer
decided no judgment was worth adding.
