name: learning
description: "When a task taught you what a later task would need: how to keep it as a skill the team can run"
---

A skill is a folder in the team's skills folder (Where things are names it) holding a SKILL.md:
front matter with `name`, the folder's name, and `description`, one sentence on what work it is
for; then how to use it. Keep what an agent can run: a script that does a step or catches a failure
in any project of its kind, and the case it caught. Improve the skill that already covers the work
instead of adding one; keep nothing you cannot run.
