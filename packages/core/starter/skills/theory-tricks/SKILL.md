# 理论论文的套路

## 什么时候用
- 题目是理论问题：为什么某现象出现（grokking、edge of stability、in-context learning、良性过拟合、缩放律），某方法什么时候有效，下界是多少；
- 实证论文需要一个“小定理”撑住核心直觉；
- 选题宽泛，想找一个简单但站得住的理论切入点。

案例见 `exemplars.md`（每篇有问题、关键技巧和“为什么简单却被接受”）。引用前先打开原文核对。

## 一、选题：简单 idea 从哪里来
1. **把现象翻译成可证明的命题**：挑一个大家都观察到、但没人在最简单模型里证明过的现象，换成“在模型 M、数据 D 下，算法 A 会/不会出现 X”。
2. **最小模型原则**：找到仍能复现现象的最小设定：线性回归、两层网络、单层注意力、对角线性网络、高斯混合、稀疏奇偶（sparse parity）、teacher-student。审稿人接受“简化”，前提是简化后现象还在，并用实验证明这一点。
3. **把 A 归约成熟悉的 B**：上下文学习 ≈ 一步梯度下降 / 岭回归；注意力 ≈ 核平滑；扩散采样 ≈ 带误差的 SDE 离散化；Adam ≈ 符号下降；残差网络 ≈ ODE 离散化。归约本身常常就是主要贡献。
4. **分离结果（separation）**：构造一个任务，证明 X 能做而 Y 不能（或指数级更费），例如“注意力 vs 循环网络”“特征学习 vs 核方法”“自回归 CoT vs 无 CoT”。
5. **上下界配对**：给出上界后再构造困难实例证明下界，两者匹配到对数因子，论文就完整了。
6. **修正一个常用假设**：把有界梯度、强凸、i.i.d.、无限宽换成更真实的条件（(L0,L1)-光滑、重尾噪声、马尔可夫数据、有限宽），说明旧结论哪里变了。
7. **理论推出可用的小改动**：从分析里读出一个超参规则或一行代码的修正（学习率与宽度的缩放、warmup 的必要性、正则化项），再用实验验证。这类论文最受 ICLR 欢迎。

## 二、常用证明技巧
- **线性化 / NTK / 惰性区间**：宽网络在初始化附近线性化，再与特征学习区间对比。
- **分阶段分析**：把训练拆成“对齐阶段 → 增长阶段 → 收敛阶段”，每段只追踪少数标量（信号分量、噪声分量）。
- **追踪少数统计量**：把高维动力学压到几个序参量（overlap、范数、margin），写成 ODE 求解或给界。
- **势函数 / Lyapunov**：构造随迭代单调下降的量，收敛速率直接读出。
- **耦合与稳定性**：算法稳定性给泛化界；对相邻数据集的两条轨迹做耦合。
- **集中不等式 + 并集界 + 覆盖数**：标准泛化界的骨架；需要更紧时换 Rademacher、PAC-Bayes 或链式论证。
- **显式构造权重**：表达能力结果直接写出 Transformer/网络的每一层参数实现某个算法（加法、排序、梯度下降一步）。
- **困难实例 + 信息论下界**：Le Cam 两点法、Fano、构造一族难以区分的分布。
- **对称性与不变量**：利用旋转/置换对称把问题降维；对角线性网络的隐式偏置来自守恒量。
- **随机矩阵与高维渐近**：比例极限 n/d→γ 下给出精确的测试误差曲线（双下降）。
- **镜像下降视角**：把重参数化后的梯度下降看成某个势函数下的镜像下降，从而读出隐式偏置。

## 三、写法与呈现
- 第 1 页就给出主定理的非形式版本（Informal Theorem 1），一句话说清“在什么条件下、什么量、什么速率”。
- 设定小节写清全部假设，每条假设后面一句话说明它为什么合理、哪里会被违反。
- 每个定理后面跟 “Proof sketch / 直觉” 段，完整证明放附录；附录按引理依赖顺序排，并画一张引理依赖图。
- 配 1～3 个**验证实验**：在最小模型里画出理论预测曲线与实测曲线重合；再在一个真实的小设定（小 Transformer、CIFAR 子集）上显示同一现象仍在。图里理论曲线用虚线。
- 讨论局限只写一两处：哪个假设最强、去掉它预计会怎样，语气平实，不写成免责清单。
- 和已有理论逐项比较：做一张表，列“设定、假设、速率、是否需要无限宽”等，本文一行加粗。

## 四、自审清单
- 定理是否非平凡：去掉某个假设后结论是否就错了（给反例最好）。
- 常数和对数因子是否诚实；“w.h.p.”的概率写明。
- 最小模型里的现象，实验上真的出现了吗？
- 记号表放附录开头，全文记号统一。
- 在库/网络上搜同名设定，确认没有撞题；与最接近的 2～3 篇理论工作的差别写进引言最后一段。
