# 不可妥协的规矩

经管期刊（JFE、TAR、RFS、Management Science、《管理世界》《经济研究》……）的图是表格的补充，不是装饰。
审稿人一眼扫过去，要看到的是一个干净的规律，而不是设计感。下面每一条都来自这些期刊已发表论文的图。

1. **颜色自由，但要克制、统一。** 颜色不限，可以用彩色；默认配色是深蓝、砖红、墨绿、灰、赭石，也可以在 spec 的
   `figure.colors` 里换成任何颜色。同一个意思全文用同一种颜色；一张图里的颜色不宜超过四五种。系列之间同时用
   标记形状或线型区分（引擎自动做），这样印成黑白也分得清。不用渐变、阴影、斜线填充。
2. **图里没有标题。** 标题写在 `\caption` 里。多面板只在左上角标 (a)(b)(c)，可以跟一个两三个字到十来个字的短名。
3. **图上不印统计结果。** 系数值、星号、p 值、t 值、“n.s.”、差异括号都在表里。图里只有点估计、置信区间和必要的参考线。
4. **一种字体、一个字号。** 与正文同一套字体（中文宋体，西文 Times 类，数学用同族数学字体），全图 8.5pt，不用粗体。
5. **按版心宽度画，放进 LaTeX 不缩放。** 宽度等于模板的 `\textwidth`（双栏期刊用 `\columnwidth`）。
6. **数据只来自论文自己的脚本。** 图和表从同一个结果文件生成，图里的每个数都能在表或结果文件里找到。没有真实微观数据时不画分箱散点。
7. **一张图只讲一个结论。** 讲不出那一句话，就不需要这张图；两个结论就两张图或两个面板。
8. **研究框架图只有构念和假设。** 方框里写构念或变量名，箭头上只标假设编号；不放系数、样本、发现。

违反第 2～5 条的，`scripts/audit.py` 会报 FAIL；第 1、6～8 条要你自己守。
