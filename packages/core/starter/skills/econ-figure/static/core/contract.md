# 动手前回答这六个问题

写进 paper/figures/FIGURE_PLAN.md（或回复里），后面改图的人照此执行。

1. **结论**：这张图要让读者记住的一句话是什么？它补充或替代了哪张表？
   例：“试点前各期系数都不显著，试点后逐年上升”——补充表 6 的事件研究回归。
2. **图型**：event-study / coefplot / binscatter / trend / distribution / framework，或几个面板的组合。
3. **数据**：CSV 由哪个脚本写出，对应哪张表的哪几列；标准误还是置信区间；置信水平；聚类层级；基期。
4. **版面**：目标期刊、模板、量出来的 `\textwidth`（pt）；单栏还是双栏；图放正文还是文末（endfloat）。
5. **名称和符号**：图里出现的每个变量名、组名、符号，与正文和表格的写法逐字一致（中文稿用中文名，英文稿用英文名）。
6. **理想数据**：图里的数字是不是理想数据（预期值）？是的话，按论文的标注规则在图题末尾加一个 †，图里不另作区分。

六个问题里有一个答不上来，先别画。
