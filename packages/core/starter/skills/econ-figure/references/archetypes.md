# 六种图型

一篇实证论文 2～4 张图就够。按论文实际做了的分析挑，宁少勿滥。下面每种图都写了：什么时候画、数据列、惯例、常见错误。

## event-study：动态效应 / 平行趋势

- **什么时候**：有 DID、多期 DID 或事件研究时**必画**；它是这类论文最重要的一张图。
- **数据**：`series`（可选，两种估计量对比时用）、`k`（相对事件的期数）、`coef`、`se`（或 `lo`、`hi`）。
- **惯例**：基期（通常 −1）在回归里省略，图上画在 0、没有区间；事件发生处画一条细点线；95% 置信区间；
  首末两期若合并了更远的期数，用 `binned_ends: true` 标成 ≤ 和 ≥。两种估计量（TWFE 与 Sun–Abraham、
  Callaway–Sant'Anna 等）并排时自动左右错开。
- **常见错误**：把基期也画上区间；纵轴不过零；在点旁标系数；用阴影带画多个系列（只有一个系列时才用 `style: band`）。

## coefplot：系数图

- **什么时候**：异质性（产权、行业、规模……）、ESG 分维度、机制变量、不同设定的稳健性，**规律比具体数字重要**时。
  若同样的数已经在表里且一眼能看出规律，就不必再画。
- **数据**：`group`（可选，分组标题）、`label`、`series`（可选）、`coef`、`se`（或 `lo`、`hi`）。
- **惯例**：横向排列（类别在纵轴）便于放长名字；零线虚线；全样本估计用 `reference` 画一条点线并标短名。
- **常见错误**：在点旁标系数和星号；画差异括号和 p 值（组间差异检验写进表或注）。

## binscatter：分箱散点

- **什么时候**：有**真实微观数据**、想展示控制固定效应和控制变量后的 Y–X 关系。理想数据论文不画：分箱点没有来源。
- **数据**：`x`、`y`（由脚本先对控制变量和固定效应取残差）；或已分好箱的 `x_bin`、`y_bin`。默认 20 箱、线性拟合。
- **常见错误**：画原始散点（几万个点糊成一片）；不取残差就说“控制后”。

## trend：年度趋势

- **什么时候**：描述核心变量的时间变化，或处理组、对照组在政策前后的均值。
- **数据**：`series`（可选）、`year`、`value`。
- **惯例**：政策年份画细点线加两三个字的标签；**两个量纲不同的变量用两个面板，绝不用双纵轴。**

## distribution：分布

- **什么时候**：安慰剂检验（随机分配处理组重复 500～1000 次的估计值分布）；两组的密度对比。
- **数据**：`series`（可选）、`value`（每次抽样一个估计值，由安慰剂脚本写出）。
- **惯例**：淡色直方图，白色细边；实际估计值用一条醒目颜色的竖线，旁边两三个字的标签；零线虚线。
  两组比较时用核密度线，靠线型区分。
- **常见错误**：叠加核密度曲线又画直方图；在图上写“经验 p 值”（写进图注）。

## framework：研究框架 / 假设关系

- **什么时候**：中文期刊较常见，英文期刊少见。可选，最多一张，放在假设一节。
- **spec**：`nodes`（`id`、`text`、`col`、`row`）、`edges`（`from`、`to`、`label`、`dashed`、`route`）、`rows`。
- **惯例**：左列解释变量、中列机制、右列被解释变量；主效应 `route: over` 从机制上方绕过，留出空的一行做通道；
  调节变量放在最上面，`to: "x->y"` 指向主效应箭头的水平段，用虚线；箭头上只标假设编号。
- **常见错误**：在框里写系数、样本量、结论；框套框；箭头穿过框。框的填充色可用节点的 `fill` 设置，宜淡。

## 多面板

- `figure.layout: [行, 列]`，`panels` 按顺序填；每个面板可加 `subtitle`（短名）。常见组合：动态效应 + 安慰剂分布；
  两个变量的年度趋势。面板之间同一类图共用纵轴含义时，纵轴名只写一次即可。
