# 交付前用眼睛过一遍

审计脚本只查规则。打开 PNG，逐条问自己：

1. **眯眼看**：模糊着看，最先看到的是不是那个结论（例如试点后的上升）？还是网格、图例、标注？
2. **盖住图题**：只看图，能不能说出横轴、纵轴、每个系列是什么？
3. **颜色统一吗**：同一个概念在各张图里是不是同一种颜色？一张图里的颜色是不是太多太杂？转成灰度后系列还分得清吗？
4. **数一数墨水**：每一笔都在传递数据吗？去掉阴影、底色、多余的边框和刻度。
5. **和表对一下**：随便挑三个点，能在表或结果文件里找到同一个数吗？
6. **和正文对一下**：变量名、组名、符号和正文、表格逐字一致吗？中文稿里有没有混进英文变量名？
7. **放到版面上看**：编译后的 PDF 里，字和正文一样大吗？图有没有被拉伸、留出大片空白？

## 一看就像计算机会议图的毛病（经管期刊里不要）

- 一张图里五颜六色、彩虹色，或同一概念在不同图里换颜色；
- 每个面板上一行粗体大标题；
- 柱子或点上标着数字、星号、“+12.3%”；
- 斜线填充、阴影、渐变、圆角卡片、图标；
- 框架图里塞满了公式、样本量和回归结果；
- teaser、案例图、照片拼贴。
